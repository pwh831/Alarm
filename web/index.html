    설정 방법

    1. 시계 앱 알람 만들기

    1. 기상 알람: 예) 7:00, 원하는 요일 반복.
    2. 백업 알람 5개: 7:03, 7:06, 7:09, 7:12, 7:15 (같은 요일 반복). 레이블을 FitWake 백업으로 해 두면 찾기 쉬워요.

    미션을 끝내기 전까지 백업 알람이 3분마다 울려요.

    2. 단축어 "FitWake 완료" 만들기

    1. 단축어 앱 → 오른쪽 위 + → 이름을 FitWake 완료로.
    2. 동작 추가 → "알람 켜기/끄기" 검색 → 백업 알람 1개 선택, 끄기로 설정.
    3. 백업 알람 5개 모두 같은 동작을 추가.

    미션을 마치면 이 페이지가 이 단축어를 실행해요.

    3. 자동화 두 개 만들기

    ① 알람을 끄면 미션 열기

    1. 단축어 앱 → 자동화 → + → 알람 → "중단될 때", 알람은 모든 알람(또는 기상·백업 알람) 선택.
    2. 즉시 실행 선택.
    3. 동작: "URL 열기" →

    ② 매일 백업 알람 다시 켜기

    1. 자동화 → + → 특정 시간 → 예) 오후 9:00, 매일 → 즉시 실행.
    2. 동작: "알람 켜기/끄기"로 백업 알람 5개를 켜기.

    4. 확인

    1. Safari에서 이 페이지 → 주소창 aA → 웹사이트 설정 → 카메라·동작 허용으로 바꾸면 매번 묻지 않아요.
    2. 1~2분 뒤로 알람을 맞추고 꺼 보세요. 미션 페이지가 열리면 성공이에요.
